# The Date Embargo

A deliberately overdramatic, bilingual TR/EN dating moratorium countdown to 1 January 2027 (Europe/Istanbul).

Static site: deploy the repository to Vercel with Framework Preset = Other, Root Directory = ./ and no build command.

The WhatsApp application is available only after every eligibility item is checked. Do not change the contact number without owner consent.

Statistics begin at July 1, 2026 and are manually configurable; no fake dates are claimed.
